# Afridha Begum — Updated Portfolio

A modern, responsive developer portfolio showcasing my projects, technical skills, and work in web development.

The website uses smooth GSAP animations and scroll-based interactions to create an engaging browsing experience while keeping the design clean and minimal.

## Features

* Modern responsive design
* Smooth GSAP animations
* Scroll-based interactions with ScrollTrigger
* Project showcase with live demos
* Skills and technology overview
* About and contact sections
* Responsive navigation
* Dark-themed interface

## Technologies

* HTML
* CSS
* JavaScript
* GSAP
* ScrollTrigger
